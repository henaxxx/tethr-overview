# Roadmap

[日本語](ROADMAP.ja.md) · [Overview](README.md)

What is planned, app by app. Dates are left out on purpose: each item ships when it is good enough, not by a fixed cut.
Status as of 2026-11-19.

## Tethr for iPhone — 1.0

| | | |
|---|---|---|
| Connect | USB. Wi-Fi at least for the Canon EOS 8000D. The camera's clock set from the iPhone. | USB done · Wi-Fi in progress |
| Shoot | Live view, shutter, exposure and ISO on cameras that allow it. Turbo: each frame taken straight from the camera's memory. | Done |
| Look and choose | The card as a list, full screen, choose many at once. | Done |
| Import | RAW, JPEG or both into Photos. From the camera, a card reader or an SSD, with progress on the Lock Screen. Keeping going after you leave the app. | Done · keeping going in the background planned |
| Develop | RAW development on the spot: the edit is kept as a recipe and the original file is never rewritten. Crop, tone curve, colour by colour. | In progress |
| Location | Where every frame was taken, written into the photos, on a map. | Done |
| Video | Importing clips from the camera and the card. Starting and stopping a recording while tethered to the 8000D. | In progress |
| With the Mac | The catalog kept in step with the Mac. Joining the Mac's own Wi-Fi network as a second screen. A read-only view of what the Mac keeps. | Done · view in progress |

Not in Tethr for iPhone: reading or deleting what is already in Photos, backups, cloud storage, accounts. Those belong to Keep and the Mac, or nowhere.
