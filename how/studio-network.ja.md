# Studio Network — Mac がネットワークになる

[English](studio-network.md) · [仕組み](README.ja.md)

Studio Network は、Mac を Wi-Fi のネットワークそのものにする。ルーターは要らず、カメラと iPhone がどこでも入れる。

このネットワークはインターネットにつながらない、閉じたもの。カメラから外へは出られない。

Tethr の入った端末は、お互いに名札を出し合って、自動で見つけ合う。見つけた相手とは、認証して暗号化した 1 本の接続を張る。
この中を、カメラの状態・撮影の命令・撮った一枚のプレビューが流れる。どの iPhone から撮っても、撮った一枚は全部の画面に届く。

今の制約: 立てている間、Mac の Wi-Fi は家のネットワークにつながらない。
チャンネルは 2.4 GHz なので、2.4 GHz だけのカメラも入れる。
